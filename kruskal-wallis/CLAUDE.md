## Project Overview

Python implementation of higher-order asymptotic approximations for the Kruskal-Wallis test statistic, based on the paper "Higher Order Asymptotic Approximations of Kruskal-Wallis Statistics Based on Skewness and Kurtosis" (Murakami, Lee & Ha, 2026). The package (`kw_approx`) provides saddlepoint, Gram-Charlier, Edgeworth, and polynomially adjusted gamma approximations to the null distribution.

## Architecture

### Core Pipeline

All approximation methods follow the same data flow:

```
sample_sizes → KWMoments (exact or simulation) → cumulants κ₁...κ₄ → approximation method → tail probability
```

**Critical design decision:** All methods use **exact finite-sample cumulants**, not asymptotic chi-square cumulants (per paper Section 4). For small N (k≤3: N≤15, k≥4: N≤13), moments come from exact distribution enumeration; otherwise from Monte Carlo simulation (50,000 iterations with deterministic seeding).

### Key Classes

- **`KWApproximator`** (`approximator.py`) — Unified entry point. Routes method-name strings (SD1, SD2, SDC1, SDC2, edgeworth, pam, etc.) to the correct approximation class. Use this for all external access.
- **`KWMoments`** (`moments.py`) — Computes raw moments → central moments → cumulants. Auto-selects exact vs simulation based on N and k.
- **`SaddlepointApproximation`** (`saddlepoint.py`) — Implements CGF approximations (ER1, ER2) with Lugannani-Rice tail probabilities (SD1), plus the gamma-based saddlepoint of Wood, Booth & Butler (1993) via `tail_probability_gamma_based` (SD2). Supports continuity correction (CC) variants. The Wang damped CGF and the unsourced "KT" CGF are preserved in comments but disabled; `cgf_method='Wang'` raises `ValueError`.
- **`ExactDistribution`** (`exact.py`) — Brute-force exact null distribution via combinatorial recursion. Only feasible for small N.
- **`PolynomialAdjustedGamma`** (`pam.py`) — PAG(d) method: gamma baseline × polynomial adjustment via moment matrix inversion. Degree 4 and 6 variants.
- **`EdgeworthApproximation`** (`edgeworth.py`) — Chi-square-based expansion with generalized Laguerre polynomials (not normal-based Hermite).
- **`GramCharlierApproximation`** (`gram_charlier.py`) — Normal-based Gram-Charlier Type A with Hermite polynomials H₃, H₄, H₆.

|-------|-------------------|-----|-----|
| SD1 | `'ER1'` / `'SD1'` | Easton-Ronchetti 1st polynomial | No |
| SD2 | `'gamma'` / `'SD2'` | Gamma-based saddlepoint (Wood-Booth-Butler 1993) | No |
| SDC1 | `'ER1_cc'` / `'SDC1'` | Easton-Ronchetti 1st polynomial | Yes |
| SDC2 | `'gamma_cc'` / `'SDC2'` | Gamma-based saddlepoint (Wood-Booth-Butler 1993) | Yes |
| CHI | `'chi_square'` | — | — |
| ED | `'edgeworth'` | — | — |
| GC-A | `'gram_charlier'` | — | — |
| PAG(4) | `'pam'` | — | — |
| PAG(6) | `'pam6'` | — | — |

### SD2 method: Wang and KT both rejected; gamma-based (WBB) used

The paper's SD2/SDC2 originally used the **Wang** damped CGF. Wang is numerically unstable near N≈15: K″(t̂) collapses toward 0 deep in the tail, blowing up the Lugannani-Rice correction term (e.g. (5,5,5) at α=0.05 returned 0.504 vs. a ~0.05 reference).

A **"Kakizawa-Taniguchi (KT)"** polynomial CGF `κ₁t + (1+κ₂)t²/2 + κ₃t³/6 + κ₄t⁴/24` was then tried, but it has **no published source**: Kakizawa & Taniguchi (1994) is a theory paper on the Edgeworth↔saddlepoint relation and proposes no CGF. The `(1+κ₂)` term inflates Var(H) by a non-vanishing ~30% (verified against χ² limit), so KT was removed.

SD2/SDC2 now use the **gamma-based saddlepoint of Wood, Booth & Butler (1993)** — a general non-normal-base Lugannani-Rice approximation that the paper already describes and cites in §4.2. Implemented in `SaddlepointApproximation.tail_probability_gamma_based` (H-scale CGF = ER1; gamma = non-normal reference base, moment-matched). Routed via the `'SD2'`/`'SDC2'` (or `'gamma'`/`'gamma_cc'`) method strings. Wang and KT code is preserved (commented out) in `saddlepoint.py`; `cgf_method='Wang'` raises `ValueError`. Paper tables are generated by `examples/reproduce_paper_tables.py` (columns `SD2(WBB)`/`SDC2(WBB)`) and converted to LaTeX by `examples/tables_to_latex.py`.

### Known Intentional Deviation from Paper

The continuity correction uses `v - 0.5` (in `tail_probability_lr` and `tail_probability_gamma_based`). The current paper PDF prescribes `v - 1/2` consistently, so code and paper now agree. The standard CC convention for P(H ≥ v) on discrete distributions is `v - 0.5` (Butler, 2007), and numerical results confirm SDC > SD (correct direction). See comments in `saddlepoint.py` (`density_approximation` / `tail_probability_lr`).
